# Presentation, menus, and feedback

Scope and rationale: presentation, menus, and feedback. Study only the selected component specifications required for the current task.

Source family: https://developer.apple.com/documentation/swiftui/modal-presentations

## P1 — Build when required — regular product feature

- [Sheet](sheet.md) — Open, close, dismiss policy and optional responsive placement.
- [FullScreenCover](full-screen-cover.md) — Full-screen overlay with safe-area and close action.
- [Popover](popover.md) — Anchored light-dismiss, controlled state, alignment and nested handling.
- [Dialog](dialog.md) — Initial focus, explicit close, cancel, result and scroll locking.
- [Alert](alert.md) — Short title/message/action pair, destructive action clear.
- [ConfirmationDialog](confirmation-dialog.md) — Confirm irreversible action; default non-destructive focus.
- [Menu](menu.md) — Action list, disabled items, separators, keyboard open/close.
- [MenuItem](menu-item.md) — Selectable action with role and disabled state.
- [Tooltip](tooltip.md) — Brief description on hover/focus with delay and dismissal.
- [Toast](toast.md) — Informational successes/failures with dedupe and optional action.
- [Banner](banner.md) — Persistent status/info with optional dismissal.
- [OverlayHost](overlay-host.md) — Centralize active overlays, unique IDs, nested close policy.

## P2 — Build on demand — complex/specialized

- [ContextMenu](context-menu.md) — Offer context-specific actions without hiding critical functionality.
- [Inspector](inspector.md) — Contextual property editing and responsive collapse.
- [CommandPalette](command-palette.md) — Open via keyboard shortcut; typed filter; execute safe commands.
